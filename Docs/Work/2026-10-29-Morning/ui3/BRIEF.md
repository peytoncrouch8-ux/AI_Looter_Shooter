# UI round 3 concepts (the user, 2026-10-29: "Let's keep improving the UI. SHOW ME SOME MORE CONCEPTS")

Six new directions for the menus and popups, after ui2/ui2.png (tag-card language on every screen, not yet picked).
Fixed for all: Slate & Salt colours (glass rgba(30,34,40,.95)->rgba(18,21,26,.93), lines #d4eef4, gold #ffe6a6 = selected,
labels #b4bec8, text #f2f6f8, flavour #ffd38a, icons #98a4ae), Chakra Petch, our own art, the game's real words.
The user's taste so far: not boxy, not bubbly; "less curvy, slightly more futuristic"; bold lines; hollow rounded keys under
panels; liked the tag card (pennant notch, toe-tag point, level gem); wants character, motion and juice; simple, not crowded.
The game: weird-west looter shooter on planet Teropa (Revenant saga: gravebound dead, roosts, embers, makers Roundhouse,
Saint Maud, Windfall, Meridian).

Each concept = one 1920x1080 PNG, the SAME three pieces so the user compares like with like:
  left big: the pause menu (GAME PAUSED, Resume, tabs Graphics/Audio/Interface/Controls, 3 rows, Save & Quit, keys);
  top right: the main menu list (REVENANT, Single Player selected, Multiplayer SOON, Settings, Quit Game);
  bottom right: the level-up popup (LEVEL UP, level 7, MAX HEALTH +8%), HUD style = no glass behind it.
A title strip names the concept in 2-5 words + one line on its idea; small notes on motion and sound.
Lane P1: concepts 1-3 -> ui3/c1.png..c3.png (script ui3/make_a.js). Lane P2: concepts 4-6 -> ui3/c4.png..c6.png (make_b.js).
Then Main joins them into ui3/sheet.png (2x3 contact sheet).
