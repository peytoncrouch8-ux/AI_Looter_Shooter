# Code map

One line per file (a `.h`/`.cpp` pair counts as one), grouped by game area: game module `Source/AI_Looter_Shooter`
first, then editor-only module `Source/LooterEditor`. Keep current when adding, moving or deleting a file. A big class
may spread its `.cpp` over files named `ClassTopic.cpp`. Tunings and step-by-step logic live in the code's comments.

## Module root
- `AI_Looter_Shooter.h/.cpp`: the module, `LogLooter` category, PIE's Stop key moved to F10 so Escape reaches the game.
- `AI_Looter_Shooter.Build.cs`: module dependencies; builds without unity.

## Core
- `Core/LooterGameMode`: `ALooterGameMode`, default mode: character/controller/HUD classes, loads the session its URL names (`?Session=N`), player start (a trip's landing, never otherwise).
- `Core/LooterMenuGameMode`: `ALooterMenuGameMode`, main menu mode (`?game=Menu`): no character, menu over the level (Lvl_MenuTeropa's World Settings name it, so it is the menu however it is opened).
- `Core/LooterMenuPlayerController`: `ALooterMenuPlayerController`, menu camera: Lvl_MenuTeropa's authored view (the camera tagged `MenuView`; slow drift, cursor parallax, 5 s ease-in; `MenuScene` tags, `ColumnEdgeNdc` -0.2 = the menu column's 40%; warns if the planet reaches the column), else circling the island. `Looter.Menu.Drift`, `.Parallax`, `.IntroSeconds`.
- `Core/LooterPlayerController`: `ALooterPlayerController`, always-on input contexts, view look limits.
- `Core/LooterCharacter`: `ALooterCharacter`, the player: move, look (sensitivity), jump, interaction; actor scaled to `Player/PlayerSize.h`; owns `UPlayerSoundComponent`, `UPlayerFootfallComponent`, `UFirstPersonHandsComponent`, `UPlayerMeleeComponent`, `UPlayerThrowComponent`, `UEmberComponent`, `UHandJarComponent`. Data-only child `/Game/Player/BP_LooterCharacter`. Steps up lips to 45 cm; keys don't steer in a mantle or vault.
