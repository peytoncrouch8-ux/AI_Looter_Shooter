# Startup logos

The startup sequence (UI/Menus/StartupLogos*) shows a placeholder studio card and a "Powered by Unreal Engine" card.

For the engine card: download Epic's official Unreal Engine logo from Epic's branding page (search "Unreal Engine branding
guidelines"), pick the white (light-on-dark) horizontal logo as a PNG, and save it here as `UnrealEngineLogo.png`. Follow
Epic's branding guidelines that come with it (don't recolor or stretch it). Main imports it as
`/Game/UI/Logos/T_UnrealEngineLogo` (the card shows a plain wordmark until then).

The studio card's name comes from config (a placeholder until the user names the studio).
